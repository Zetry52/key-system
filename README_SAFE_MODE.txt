Файлы для зачистки лежат в этой папке:

1. run-safe-mode-cleanup.cmd
2. safe-mode-cleanup.ps1
3. winre-offline-clean.cmd

Как использовать:

Вариант 1. Безопасный режим
1. Загрузись в безопасный режим с командной строкой или обычный безопасный режим.
2. Открой CMD или PowerShell от имени администратора.
3. Перейди в эту папку.
4. Запусти:
   run-safe-mode-cleanup.cmd
5. Дождись окончания.
6. В этой же папке появится лог вида:
   safe-mode-cleanup-YYYYMMDD-HHMMSS.log
7. Перезагрузи ПК в обычный режим и проверь:
   - открывается ли Task Manager
   - не закрывается ли explorer.exe
   - нет ли задач CashClean / OnlogonCheck / ServiceManager / WinlogonCheck / CreedMobe

Вариант 2. Если в безопасном режиме остался Access denied
1. Загрузи WinRE:
   Shift + Перезагрузка -> Поиск и устранение неисправностей -> Дополнительные параметры -> Командная строка
2. Найди букву системного диска. В WinRE это может быть не C:
3. Перейди в папку с этими файлами.
4. Запусти:
   winre-offline-clean.cmd
5. Когда скрипт спросит букву диска Windows, введи ее без двоеточия.
   Пример: C
6. После выполнения перезагрузи систему.

Что делает safe-mode-cleanup.ps1:
- восстанавливает Winlogon
- снимает типовые блокировки Task Manager / CMD / Regedit
- удаляет вредоносные Run-ключи
- пытается удалить вредоносные задачи планировщика
- пытается удалить файлы этих задач и их TaskCache
- чистит подозрительные WMI subscriptions по ключевым словам
- удаляет найденные папки ReaItekHD / RealtekHD и файлы CreedMobe*

Что делает winre-offline-clean.cmd:
- удаляет задачи офлайн из System32\Tasks
- удаляет их TaskCache из SOFTWARE hive офлайн
- восстанавливает Winlogon офлайн
- удаляет вредоносный Run-ключ офлайн
- снимает типовые политики офлайн

После успешной зачистки рекомендую:
1. Запустить Windows Defender Offline scan
2. Проверить планировщик задач еще раз
3. Сменить пароли от важных аккаунтов
